Aanmeldmodus: aanvragen, wachtlijst of 30 dagen proef

De superadmin kiest hoe nieuwe handelaren binnenkomen. Kiest hij voor de proef, dan maakt de handelaar direct een shop aan en komt hij na het bevestigen van zijn e-mail meteen in de setup-wizard. Er hoeft niemand iets goed te keuren.

1 · De instelling

Platform → Aanmeldingen → Aanmeldmodus

Bovenaan de bestaande pagina /admin/platform/applications. De keuze geldt voor nieuwe aanmeldingen. Aanvragen die al openstaan, blijven gewoon in de lijst.

2 · De drie routes

Wat een handelaar meemaakt

Aanvragen

bestaat al
Formulier→ E-mail bevestigen→ Superadmin keurt goed→ Uitnodigingsmail→ Wachtwoord→ Wizard

Wachtlijst

nieuw
Formulier→ E-mail bevestigen→ Op de wachtlijst→ Superadmin: Uitnodigen→ Uitnodigingsmail→ Wachtwoord→ Wizard

"Uitnodigen" doet hetzelfde als goedkeuren nu: shop, subdomein, eigenaar en uitnodiging. Afwijzen kan ook, met reden.

30 dagen proef

nieuw
Formulier→ E-mail bevestigen→ Shop wordt aangemaakt→ Direct: wachtwoord kiezen→ Wizard

De bevestigingsknop stuurt meteen door naar <shop>.woutvanderpol.nl/admin/accept-invite, zonder tweede mail. De uitnodigingsmail gaat wel mee als reserve, voor wie het tabblad sluit.

De e-mailbevestiging blijft in alle drie de routes. Zonder die stap kan iedereen met een nep-adres een shop op ons domein aanmaken.

6 · Techniek

Wat er onder de motorkap verandert

Data

enum SignupMode { APPLY WAITLIST TRIAL }

model PlatformConfig {      // één rij, id = 1
  id         Int        @id @default(1)
  signupMode SignupMode @default(APPLY)
  trialDays  Int        @default(30)
  updatedAt  DateTime   @updatedAt
}

enum DealerApplicationStatus {
  PENDING  WAITLISTED  APPROVED  REJECTED
}

model Tenant { … trialEndsAt DateTime? }

Code

  • submitApplication zet de status op PENDING of WAITLISTED, afhankelijk van de modus.
  • verifyApplicationEmail: in de proefmodus wordt de aanvraag automatisch goedgekeurd (zelfde transactie als goedkeuren nu, met trialEndsAt), en wordt de uitnodigingslink teruggegeven voor de redirect.
  • Wachtlijst: geen superadmin-mail per aanmelding. Uitnodigen gebruikt approveApplication.
  • Proefshops: superadmin krijgt de melding "nieuwe proefshop".
  • Dagelijkse job trials.tick: herinneringsmails en het verlopen van proeven.
  • Rate limits, Turnstile, honeypot en de duplicaatchecks blijven gelijk. Een e-mail of KvK die al een shop heeft, krijgt geen tweede proef.
  • Tests voor de drie modi, de auto-goedkeuring en het verlopen.
7 · Besluiten (29-10-2026)

Jouw keuzes

  1. Proefshop mag direct live, ook met echte betalingen.Jij krijgt een melding per nieuwe proefshop en kunt hem altijd blokkeren.
  2. Na de proef: winkel dicht, admin open.Bezoekers zien "Tijdelijk gesloten", gegevens blijven. Jij verlengt of zet om naar betaald.
  3. Pakket tijdens de proef: Compleet.De handelaar ziet alle modules.
  4. Wachtlijst: alleen "je staat op de lijst".Geen plek in de rij voor de aanmelder; jij ziet de volgorde wel.
