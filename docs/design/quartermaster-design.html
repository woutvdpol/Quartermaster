Admin Shop

Wat we oplossen

Geen één-op-één port. Deze punten uit de analyse krijgen in Quartermaster een andere opzet.

Order-afrondingNu: voorraad en mails pas op de bedankpaginaStraks: idempotente Mollie/PayPal-webhook + job-queue
Unieke items dubbel verkochtNu: geen reservering bij bestellenStraks: reservering per mandje met aftelklok, atomaire voorraad
RechtenNu: owner kan via URL bij Rollen; mutaties via GETStraks: RBAC-check per actie, alleen POST, audit-log, 2FA
StatussenNu: losse strings, geen verzendstatus, geen factuurStraks: betaal- en verzendstatus, historie, factuur-PDF
InstellingenNu: ~60 key/value-rijen, type geraden uit naamStraks: getypeerde groepen met eigen formulier
ContentNu: twee CMS'en naast elkaarStraks: één block-CMS

Fasering

Admin wordt gebouwd en getest op een kopie van de echte data. Admin en shop gaan samen live.
