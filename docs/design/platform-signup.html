Open questions for the owner

  1. Nav CTA on sign-up pages. I dropped the brass CTA button (“Start free trial”), because it would link to the page you are already on, or to a sign-up you just made. The rest of the landing nav stays. Should it come back?
  2. Concept500. “Concept500” is still one of the “Where do you sell now?” options, because the review uses that answer. The wizard step no longer names it, to match the landing. Should the option stay?
  3. Chamber of Commerce number. The schema accepts an empty value, but the label does not say “optional”, and the landing step says “your Chamber of Commerce number”. Should the field be marked optional, or made required?
  4. TRIAL confirm button. The mail button says “Confirm and create my shop”, the page button says “Confirm my email”. I kept the page text, because a trial can be held for review, and then no shop is created. Should the two match?
  5. “Your shop is created the moment you click”. This is not true when autoTrialBlockers holds a trial for review. The dealer then sees “Email confirmed. We review your application”. Is that wording acceptable, or should the TRIAL copy hedge?
  6. Mobile order. On mobile the steps come before the form, in the same reading order as desktop. Should the form come first instead?
  7. Duplicate email. There is no form error for it: the server says ok, sends the link again if the address is not yet confirmed, and shows the thanks page. That keeps addresses from being probed. Is that the intended behaviour?
